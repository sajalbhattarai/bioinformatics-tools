operon-db.pkl -- MARGIE's starter operon reference (OCC reference v1)
=====================================================================

What it is
----------
The cross-genome operon reference that MARGIE's scoring step reads to compute
C3, the operon-context confidence of each gene. It holds additive counts of how
often pairs of gene descriptors sit next to each other (adjacency) and in the
same operon (co-operon) across the genomes it was built from. Only "qualifying"
operons count: those where informative members outnumber uninformative ones
(for example "hypothetical protein"). c3_occ.py builds, updates and scores
against it; c3_occ.load_reference() reads it.

Why it ships with MARGIE
------------------------
On a fresh install there is no reference yet, so the first genome would be
scored against nothing. update-occ-reference-depot.py copies this file into
place the first time a run needs a reference, and every genome annotated after
that is added to the copy. The copy, not this file, is what grows:

  cluster (margie-backend / margie_sb.smk):  <your store>/operon-database/occ_reference.pkl
  this computer (margie-pipeline):           $MARGIE_SHARED_DIR/operon-database/occ_reference.pkl

Scoring leaves the genome being scored out of the reference (matched by content
fingerprint, else by name), so a genome that is already in here is not scored
against itself.

Format
------
Python pickle of one dict, schema version 2 (c3_occ.REF_VERSION):
  version               2
  present               descriptor -> number of organisms it is present in
  adj_org, adj_inst     adjacent descriptor pair -> organisms / instances
  coop_org, coop_inst   co-operon descriptor pair -> organisms / instances
  deg_adj, deg_op       per-descriptor degrees for the two channels
  M_adj, M_op           totals for the two channels
  n_qualifying_operons  number of operons counted
  organisms_added       the organisms it was built from (names below)
Open it only with the matching c3_occ.py; the version check refuses others.

Rebuilding
----------
A reference can be rebuilt from any set of annotated genomes with
scoring/analysis/c3_figures/score_occ.py build, or grown one genome at a time
with update-occ-reference-depot.py, which is what a run does.
